# Dashboard Brief Canvas — ExerLink

Use case: ติดตามผลการจับคู่ของเสียในนิคมฯ นำร่อง เพื่อตัดสินใจว่าเดือนนี้จะส่งทีมไปทำงานที่ไหน

| ช่อง | คำตอบ | มาจาก BMC | อยู่ในข้อมูล / dashboard ตรงไหน |
|---|---|---|---|
| 1. User | ผู้จัดการโครงการ ExerLink ประจำนิคมฯ และวิศวกรในทีม | Key Resources · Customer Relationships | บรรทัดใต้ header |
| 2. Decision | เดือนนี้ส่งวิศวกรไปทำงานกับโรงงาน/ของเสียไหน และควรคุยต่อสมาชิกกับใคร | Cost Structure (วิศวกร ~60%) · Value Proposition (ลดต้นทุน 10–20%) · Customer Relationships (ทดลองฟรี 3 เดือน) | หัวเรื่อง (headline) + แผง 3 |
| 3. Metric | % ต้นทุนที่ลดได้ · % ไปหลุมฝังกลบ · ตันที่เลี่ยงหลุมฝังกลบ · ดีลที่ปิดได้ · อัตราต่อสมาชิก | Value Proposition · Revenue Streams | แถว KPI · ชีต `Monthly` |
| 4. Grain | 1 แถว = โรงงาน × ชนิดของเสีย × เดือน | Key Activities (ทะเบียน DIW + รหัสของเสีย) | `fact_factory_stream_month.csv` / ชีต `Fact` |
| 5. Dimension | เดือน · โรงงาน/ขนาด S-M-L · สถานะลูกค้า · ชนิดของเสีย · ใบอนุญาตผู้รับ | Customer Segments · Key Partners | ตัวเลือกเดือน · ปุ่มกลุ่มโรงงาน · `dim_factory.csv` · `dim_stream.csv` |
| 6. Action | ทดลองใกล้หมด → นัดคุยต่อ · ประหยัดเกินเป้าแต่ไม่ต่อ → ส่งรายงานผล · ต่ำกว่า 5% → ส่งวิศวกรหาผู้รับ · กลุ่มรวมของ → ชวนเพิ่ม | Key Activities · Value Proposition | แผง 3 "ทำอะไรต่อ" |

## เหตุผลที่เลือก chart

- **Line + แถบเป้าหมาย** (chart หลัก): ผู้ใช้ต้องรู้ว่าถึงเป้าหรือยัง และกำลังดีขึ้นหรือแย่ลง เส้นแสดงทิศทางตามเวลา แถบส้มทำให้เห็นทันทีว่าเดือนไหนต่ำกว่าเป้า
- **Bar แนวนอนรายโรงงาน ระบายสีตามสถานะ**: ชื่อโรงงานยาวอ่านง่ายในแนวนอน เส้นเป้า 10% กับสีสถานะทำให้เห็นในภาพเดียวว่าโรงงานที่ไม่ต่อสมาชิกส่วนใหญ่ประหยัดเกินเป้า
- **KPI cards**: สถานะรวมใน 5 วินาทีแรก พร้อมลูกศรเทียบเดือนก่อน

## กฎ Alert

1. โรงงานทดลองฟรีเหลือ ≤ 14 วัน → ด่วน: นัดคุยต่อสมาชิก
2. โรงงานหมดทดลอง-ไม่ต่อ แต่ % ลดต้นทุน ≥ 10% → โอกาส: ส่งรายงานผลประหยัด
3. โรงงานที่ % ลดต้นทุน < 5% → ส่งวิศวกรหาผู้รับให้ของเสียที่ยังไปหลุมฝังกลบมากที่สุด
4. กลุ่มรวมน้ำมันใช้แล้วยังไม่ถึง 5 ตัน → ชวนโรงงานเข้ากลุ่มเพิ่ม
