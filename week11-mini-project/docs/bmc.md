# Business Model Canvas — ExerLink

| ช่อง BMC | รายละเอียด |
|---|---|
| **Key Partners** | ผู้บริหารนิคมฯ (อมตะ / ปิ่นทอง / กนอ.) ประตูเข้าถึงลูกค้า · ส.อ.ท. (Circular Material Hub) เชื่อมข้อมูล ไม่แข่ง · โรงงานรับกำจัด 101/105/106 และผู้ขนส่งที่มีใบอนุญาต · มหาวิทยาลัย (แล็บวิเคราะห์ตัวอย่าง + ความน่าเชื่อถือ) · กรอ. / สอจ.ชลบุรี (ที่ปรึกษาด้านระเบียบ) |
| **Key Activities** | รวบรวมและทำความสะอาดข้อมูล (ทะเบียน DIW + รายชื่อผู้รับกำจัด) · เอนจินจับคู่แบบกฎ (รหัสของเสีย × วัตถุดิบ × ระยะทาง) · ใช้ LLM แปลงคำอธิบายของเสียเป็นรหัสมาตรฐาน · วิศวกรตรวจทุกคู่ก่อนส่งลูกค้า · ลงพื้นที่หาผู้ใช้ฝั่งแรก + ทำ NDA |
| **Key Resources** | ฐานข้อมูลคู่ที่จับสำเร็จจริง · วิศวกรสิ่งแวดล้อมที่รู้กฎหมายกากอุตสาหกรรม · MOU กับนิคมฯ + อาจารย์ที่ปรึกษา · ข้อมูลเปิด DIW, gdcatalog, ค่า EF จาก TGO · ระบบเว็บ + ฐานข้อมูล + API แผนที่ |
| **Value Proposition** | รวมของเสีย SME หลายรายให้ได้ปริมาณที่ผู้รับซื้อสนใจ · เปลี่ยนค่ากำจัดเป็นรายได้ (เป้านำร่องลดต้นทุน 10–20%) · คัดกรองใบอนุญาตผู้รับตรงรหัสของเสียก่อนยื่น กอ.1/กอ.2 · จับคู่เชิงรุก · ใบสรุปตันที่เลี่ยงหลุมฝังกลบ + kgCO₂e อ้างอิง EF ของ TGO |
| **Customer Relationships** | ดูแลรายบัญชีแบบทำมือ 20 โรงงานแรก · นำร่องฟรี 3 เดือน แลกสิทธิ์ใช้ข้อมูลทำกรณีศึกษา · รายงานสรุปรายไตรมาส · กลุ่มผู้ใช้ในนิคม (LINE + เวทีพบปะรายไตรมาส) |
| **Channels** | ทีมขายลงพื้นที่ผ่านสำนักงานนิคมฯ · งานสัมมนา กรอ. / กนอ. / ส.อ.ท. · ที่ปรึกษา ISO 14001 และ Green Industry · เว็บ + LINE OA |
| **Customer Segments** | SME ในนิคมฯ ที่ไม่มีทีมสิ่งแวดล้อม · โรงงานรีไซเคิล 105/106 ที่ต้องการวัตถุดิบสม่ำเสมอ · ผู้บริหารนิคมฯ ที่ต้องรายงานตัวชี้วัดเมืองอุตสาหกรรมเชิงนิเวศ · (ระยะ 2) โรงงานส่งออกที่ต้องรายงาน Scope 3 / CBAM |
| **Cost Structure** | ค่าแรงวิศวกร + ทีมลงพื้นที่ ~60% · ต้นทุนหาลูกค้าฝั่งแรก (CAC) · ค่าวิเคราะห์ตัวอย่างในแล็บ · ค่า cloud + LLM API · ค่าที่ปรึกษากฎหมาย + ประกันความรับผิด |
| **Revenue Streams** | Resource mapping 150,000–400,000 บาท/โครงการ · สมาชิกรายปี S 12,000 / M 30,000 / L 60,000 บาท · คอมมิชชัน 3–5% · ค่าเตรียมเอกสาร กอ.1/กอ.2 1,500–3,000 บาท/รายการ · งบสนับสนุนโครงการเมืองอุตสาหกรรมเชิงนิเวศ |
